# 앱 구조 — 독자 앱과 파트너 앱의 탭 기준선

| 항목 | 내용 |
|---|---|
| 종류 | 구조 |
| 상태 | 확정 |
| 브랜드 | reader · partner |
| 담당 | 기획 @ · 디자인 @ · 개발 @ |
| 현황 버전 | a1b2c3d |

> 화면은 `shell.js`(모든 화면 위의 앱 셸)와 사이트맵이다. 셸을 바꾸면 **모든 화면의 메뉴가 같이 바뀐다** — PR 화면 비교에서 확인한다.

## 결정

- 앱을 **둘로 나눈다** — 책숲(독자)·책숲 파트너(사장님). 한 앱에 모드 전환을 두면 메뉴가 두 벌로 섞인다.
- 탭은 앱마다 **최대 5개**. 넘치면 묶거나 다른 탭 안으로 넣는다.
- 하지 않기로 한 것: 독자 앱 안에 사장님 메뉴 — 권한이 다른 메뉴가 한 화면에 섞인다.

## 화면 지도

| 앱 | 탭 |
|---|---|
| 책숲 | 홈 · 모임 · 챌린지 · 퀴즈 · 내 서재 |
| 책숲 파트너 | 대시보드 · 모임 운영 · 퀴즈 · 내 서점 |

## 이동 규칙

- 로그인이 필요한 탭을 비로그인이 누르면 로그인 → 누른 탭으로 돌아온다.
- 두 앱에 다 있는 기능(모임)은 같은 주소를 쓰고, 앱이 다르면 그 앱에 맞는 화면을 보여 준다.

## 영향 받는 화면

모든 기능 화면 — `book-club`, `reading-challenge`, `book-quiz`.
