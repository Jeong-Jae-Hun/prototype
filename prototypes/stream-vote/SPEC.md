# 다음 방송 투표 — 방송인이 올린 후보에 멤버가 투표해 다음 방송 내용을 정한다

| 항목 | 내용 |
|---|---|
| 상태 | 초안 |
| 담당 | 기획 @ · 디자인 @ · 개발 @ |
| 최종 결정권자 | @ (사업 결정이 갈릴 때만) |

> 프로토타입과 이 문서가 어긋나면 이 문서가 맞다.

## 결정

- **투표는 멤버만 한다.** 로그인만 한 일반 회원과 비로그인은 후보와 최종 결과를 볼 수 있지만 투표는 못 한다.
  다음 방송을 정하는 힘을 멤버 혜택으로 둔다. 로그인만으로 열면 다른 채널 팬이 몰려와 결과를 흔들 수 있다.
- **한 사람 한 표, 단일 선택.** 복수 선택은 "가장 보고 싶은 하나"라는 질문을 흐린다.
- **마감 전까지 표를 바꿀 수 있다.** 바꾸면 이전 표는 사라지고 새 표만 남는다. 취소(기권)는 없다 — 바꾸기만 된다.
- **득표는 마감 후에 공개한다.** 진행 중에는 참여자 수만 보인다. 앞선 후보로 표가 쏠리는 것을 막는다.
  방송인과 운영자는 진행 중에도 득표를 본다(방송 준비·운영 개입에 필요).
- **누가 어디에 투표했는지는 아무에게도 보이지 않는다** — 방송인·운영자 포함. 화면에는 후보별 표 수만 나온다.
  공개 근거: 표 수 집계는 익명 집계라 공개한다. 개인의 선택은 공개 근거가 없다.
- **투표를 시작하면 후보·질문을 고칠 수 없다.** 오타라도 고칠 수 없다. 이미 투표한 사람이 고르지 않은 후보로
  표가 옮겨지는 결과가 생기기 때문이다. 고쳐야 하면 투표를 취소하고 새로 만든다.
- **방송인은 일찍 마감할 수 있다.** 확인을 한 번 더 받고, 결과 화면에 "방송인이 일찍 마감했어요"를 표시한다.
- **마감 시각이 되면 자동으로 마감한다.** 1위가 하나면 바로 결과 발표, 동점이면 「마감(동점 결정 대기)」으로 간다.
- **동점은 방송인이 동점 후보 중에서 고른다.** 정해진 시간 안에 안 고르면 먼저 등록한 후보로 정해진다.
  0표로 끝나도 같은 규칙이다(모든 후보가 동점).
- **채널에 열린 투표는 한 번에 하나.** 새 투표는 이전 투표가 결과 발표·취소된 뒤에만 만든다.
- **운영자는 투표를 숨길 수 있다.** 사유 입력이 필수이고 감사 기록이 남는다. 숨김 해제도 같다.
  운영자는 투표하지 않는다(운영자 계정이 그 채널 멤버여도 운영자 보기에서는 투표 버튼이 없다).

### 하지 않기로 한 것

- 복수 선택·순위 투표 — 질문이 흐려지고 집계 규칙 설명이 길어진다.
- 진행 중 득표 실시간 공개 — 위 쏠림 이유.
- 투표 시작 후 후보 추가·수정·삭제 — 위 공정성 이유.
- 마감 연장 — 정해진 마감을 믿고 투표한 사람을 기준으로 한다. 늘리고 싶으면 취소 후 다시 연다.
- 결과가 다음 방송 일정을 자동으로 만드는 것 — 결과 발표까지만 한다. 일정 등록은 방송인이 따로 한다.
- 포인트·재화로 표를 더 사는 것 — 사업 결정이 아니라 기능 범위 밖으로 둔다. 다시 꺼내려면 남은 질문에 올린다.

## 상태 변화

| 지금 | 계기 | 다음 | 되돌리기 |
|---|---|---|---|
| 투표 전 | 방송인이 「투표 시작」 | 진행 중 | 투표 취소로만 (표가 없을 때도 같은 경로) |
| 진행 중 | 마감 시각 도달, 1위 하나 | 결과 발표 | 불가 |
| 진행 중 | 마감 시각 도달, 동점 | 마감 (동점 결정 대기) | 불가 |
| 진행 중 | 방송인이 「일찍 마감」 확인 | 결과 발표 또는 마감 (동점) | 불가 |
| 진행 중 | 방송인이 「투표 취소」 확인 | 투표 전 (표 전부 폐기, 멤버에게 취소 알림) | 불가 |
| 마감 (동점) | 방송인이 동점 후보 하나 고름 | 결과 발표 | 불가 |
| 마감 (동점) | 결정 대기 시간 경과 | 결과 발표 (먼저 등록한 후보) | 불가 |
| 결과 발표 | 방송인이 「새 투표 만들기」 | 투표 전 (새 투표) | 이전 투표는 기록으로 남는다 |
| 어느 상태든 | 운영자가 숨김 | 같은 상태 + 숨김 | 운영자가 숨김 해제 |

예외 흐름

- **마감 순간에 들어온 표** — 서버가 받은 시각 기준. 마감 시각 이후 도착한 표는 거부하고 "투표가 끝났어요"를 보여 준다.
- **같은 사람이 두 기기에서 동시에 투표** — 한 사람 한 표가 저장 단위다. 나중에 저장된 쪽이 남는다(바꾸기와 같다).
- **숨김 중 마감 시각 도달** — 마감·결과 발표는 그대로 진행한다. 숨김은 보이는지 여부만 바꾼다.
- **방송인이 결정 대기 중 채널을 떠남(탈퇴·정지)** — 결정 대기 시간 경과 규칙으로 정해진다.
- **투표 중 멤버십이 끝난 사람의 표** — 남은 질문 참고.
