## 결정

- **챌린지는 책숲 운영이 여는 월 단위 행사다.** 예: "10월 챌린지 · 한 달에 3권". 한 번에 하나만 열린다. 서점이 여는 모임(`book-club`)과 다르다 — 책숲 파트너(`partner`)에는 화면이 없다.
- **참가는 무료다.** 참가비·포인트 차감이 없다. 참가 확인 화면에 "참가비 없음 · 포인트가 차감되지 않아요"를 확정 버튼 앞에 쓴다.
- **시작 전에도 참가할 수 있다.** 미리 참가하면 시작일에 알림을 받는다. 인증은 시작일부터다. 진행 중에도 참가할 수 있다(늦게 들어와도 같은 조건).
- **인증 = 다 읽은 책 한 권 + 한 줄 감상.** ISBN(10·13자리), 책 제목, 한 줄 감상(10~100자)이 필수, 사진은 선택이다.
- **부정 인증은 막기보다 비싸게 만든다.** 완독을 기계로 증명할 방법은 없다. 그래서
  1. 같은 ISBN은 **독자당 평생 한 번**만 인정한다 — 이번 챌린지 안에서도, 지난 챌린지에서 인증한 책도 다시 안 된다(재독은 인정하지 않는다. 남은 질문 참고).
  2. **하루 인증 상한**(2권)을 둔다. 마지막 날 몰아서 채우는 것을 막는다.
  3. 감상 최소 글자(10자)를 둔다.
  4. 나머지는 사후에 잡는다 — 공통 **신고**와 운영자 **검수**로 인증을 취소한다.
- **ISBN 없는 책**(독립출판 일부)은 제목으로 인증하고 자동으로 **운영자 검수 대상**에 오른다. 서점 임시 코드는 독자가 알 수 없으므로 요구하지 않는다.
- **보상은 지급 시점을 늦춰서 회수를 줄인다.** 달성해도 바로 주지 않고, 기간 종료 후 **검수 기간 3일**이 지난 뒤 운영자가 일괄 지급한다. 이 기간에 신고·검수를 끝내 두면 지급 후 회수가 드물어진다.
- **보상은 이벤트 지급분 포인트만 쓴다.** 결제 적립분과 섞지 않는다(아래 「충돌」).
- **공개 범위 — 기본은 나만 보기.** 인증마다 "다른 참가자에게 감상 공개"를 고를 수 있고, 공개해도 **닉네임·책 제목·한 줄 감상만** 나간다. 사진은 공개하지 않는다(집·얼굴이 찍히기 쉽다). 공개 감상은 **그 챌린지 참가자에게만** 보인다. 비참가 독자·비로그인은 집계만 본다.
- **순위표를 만들지 않는다.** 누가 몇 권 읽었는지는 남에게 보이지 않는다. 화면에는 집계(참가자 수·달성자 수)만 있다. 순위는 몰아 읽기·부정 인증의 동기를 키우고, 독서량은 개인 정보다.
- **중도 포기**: 시작 전·진행 중에 "참가 그만두기"를 할 수 있다. 그만두면 **그 챌린지에는 다시 참가할 수 없고** 보상 대상에서 빠진다. 인증한 책 기록은 내 서재에 남는다. 달성 후에는 그만두기 버튼이 없다.
- **운영자 인증 취소**: 사유 필수, 참가자·신고자에게 알림. 취소로 권수가 달성 조건 밑으로 떨어지면
  - 지급 전: 달성이 풀린다. 회수할 것이 없다.
  - 지급 후: 달성이 풀리고 지급한 보상을 **이벤트 지급분에서 회수**한다. 이벤트 지급분 잔액이 모자라면 남은 만큼만 회수하고 부족분은 감사 기록에만 남긴다(마이너스 잔액을 만들지 않는다. 결제 적립분에서 빼지 않는다).
- **참가자 본인은 자기 인증을 지울 수 있다**(진행 중에만). 지우면 권수가 줄고, 그 ISBN은 다시 쓸 수 있다. 종료 후에는 못 지운다(지급 대상 산정이 흔들린다). 화면에는 없다.
- **하지 않기로 한 것**: 순위표·배지 경쟁, 독자 간 인증 "좋아요", 서점별 챌린지, 사진 필수, 완독 퀴즈(문항 관리 비용이 크다), 자동 지급(총액을 사람이 보고 지급한다).

- 공개 감상의 공개 근거: 작성자가 인증마다 "참가자에게 공개"를 직접 골랐을 때만, 같은 챌린지 참가자에게만. 닉네임 외 식별자(내부 id)는 내보내지 않는다.
- 공개 범위·권수 숨김은 **서버가 막는다.** 화면에서 숨기는 것으로 대신하지 않는다. 공개 감상 목록 API는 작성자 권수·달성 여부를 응답에 담지 않는다.

## 상태 변화

챌린지 단계(운영)와 참가자 상태(개인)가 따로 있다. 보기 전환의 「달성」「보상 지급됨」은 참가자 상태다 — 참가자가 아닌 역할에는 각각 진행 중·기간 종료 화면으로 보인다.

| 지금 | 계기 | 다음 | 되돌리기 |
|---|---|---|---|
| (없음) | 운영자가 챌린지 생성 | 시작 전 | 운영자가 시작 전에 삭제 가능 |
| 시작 전 | 시작일 00:00 (KST) | 진행 중 | 불가. 이후 설정 잠김 |
| 진행 중 | 종료일 23:59 지남 | 기간 종료 | 불가 |
| 기간 종료 | 검수 기간 3일 지남 + 운영자 지급 실행 | 지급 완료 | 불가 (개별 회수만) |
| 독자 | 참가하기 | 참가자(0권) | 그만두기로만 — 재참가 불가 |
| 참가자 | 인증으로 권수 = 목표 | 달성(지급 대기) | 본인 삭제·운영자 취소로 목표 밑이 되면 참가자로 |
| 달성(지급 대기) | 운영자 지급 실행 | 보상 지급됨 | 운영자 취소로 목표 밑이 되면 회수 → 미달성 |
| 참가자 | 기간 종료 시 권수 < 목표 | 미달성 | 불가 (보상 없음, 기록은 남음) |
| 참가자 | 그만두기 | 포기 | 불가 |

예외 흐름

- **ISBN 중복**: 이번 챌린지에 있는 ISBN → "이미 이번 챌린지에서 인증한 책이에요". 지난 챌린지의 ISBN → "지난 챌린지에서 인증한 책이에요". 운영자가 취소한 인증의 ISBN은 다시 쓸 수 없다(같은 책으로 재시도 방지).
- **하루 상한 초과**: 인증 버튼이 "오늘은 2권까지 인증했어요 · 내일 다시"로 잠긴다. 하루 기준은 KST 00:00.
- **동시 요청**: 같은 독자가 두 기기에서 동시에 인증하면 서버가 ISBN 유일성·하루 상한을 한 트랜잭션에서 판정한다. 진 쪽은 위 오류 문구를 받는다.
- **종료 직전 인증**: 서버 수신 시각 기준. 23:59:59 이후 도착분은 "기간이 끝났어요"로 거절한다(조용히 버리지 않는다).
- **검수 기간 중 미처리 신고**: 지급 실행 시 검수 중인 인증이 있는 참가자는 이번 지급에서 빠지고, 처리 후 개별 지급된다. 지급 확인 화면에 남은 건수를 보여 준다.
- **지급 실패**(포인트 원장 오류): 참가자별로 재시도 목록에 남고 운영자 화면에 실패 건수를 띄운다. 성공한 사람만 "지급됨" 알림을 받는다.
- **회수 시 잔액 부족**: 이벤트 지급분 잔액까지만 회수, 부족분은 감사 기록. 참가자에게 회수 금액을 알림으로 알린다.
- **불러오기 실패**: 진행 막대·인증 목록을 못 불러오면 "0권"으로 그리지 않는다. "불러오지 못했어요 · 다시 시도"를 보여 준다.

## 숫자

| 값 | 얼마 | 운영이 배포 없이 바꾸나 |
|---|---|---|
| 달성 권수 | 3권 | 예 (→ 어드민 화면 필요). 챌린지마다, 시작 전에만 |
| 달성 보상 | 300P (이벤트 지급분) | 예 (→ 어드민 화면 필요). 시작 전에만. 금액 확정은 남은 질문 |
| 하루 인증 상한 | 2권 | 예 (→ 어드민 화면 필요). 시작 전에만 |
| 한 줄 감상 길이 | 10~100자 | 아니오 |
| 검수 기간(종료 → 지급) | 3일 | 아니오 |
| 챌린지 기간 | 한 달(1일~말일) | 아니오 |
| 동시에 열리는 챌린지 | 1개 | 아니오 |

진행 중에 숫자를 바꾸지 않는 이유: 이미 참가한 사람의 조건이 바뀌면 형평 문제가 생기고, 달성자 산정이 흔들린다.

| 구분 | 무엇 | 근거 |

| 재사용 | 알림 — 시작·달성·지급·회수·취소 사유·신고 결과. 종류만 추가, 묶음 규칙(10분 1건) 그대로 | `context/features.md` 알림, `context/constraints.md` 알림 묶음 |
| 재사용 | 운영자 조작 감사 기록 — 설정 변경·인증 취소·지급·회수·사진 열람 | `context/constraints.md` 어드민 감사 기록, `context/rules.md` 운영 |
| 재사용 | 책 식별은 ISBN | `context/constraints.md` "책은 ISBN 으로 식별한다" |
| 신규 | 챌린지(기간·조건) · 참가 · 인증 데이터, 독자 앱 챌린지 탭 | 비슷한 기능 없음. 셸에 `챌린지` 탭이 이미 자리 잡혀 있다(`app-structure/shell.js`) |
| 신규 | 어드민 › 챌린지 설정(권수·보상·하루 상한) · 검수 · 지급 화면 | `context/features.md` "운영이 바꾼다로 정하면 어드민 화면이 같이 필요" |

| 충돌 | ISBN 없는 책 — 서점 임시 코드는 독자가 모른다. 제목 인증 + 운영자 검수로 우회한다 | `context/constraints.md` "ISBN 없는 책은 서점이 임시 코드를 받는다" |
