# 책 퀴즈 — 서점이 낸 책 퀴즈를 독자가 풀고 정답자에게 포인트를 주는 기능

## 결정

- **사장님이 3~5문항 객관식(선택지 4개) 퀴즈를 내고, 독자는 한 문항씩 풀어 한 번만 제출한다.** 재도전은 없다 — 다시 풀 수 있으면 답을 바꿔 가며 정답을 찾아낼 수 있다.
- **정답과 내 결과는 마감 뒤에 공개한다.** 제출 직후 공개하면 진행 중에 정답이 퍼진다.
- **보상은 만점자 전원에게 책숲 이벤트 포인트.** 사장님은 포인트를 직접 주지 않는다 — 원장의 이벤트 지급분으로 책숲이 지급한다(결제 적립분 환불 규정을 피한다).
- **서점은 집계만 본다**(참여 수·문항별 정답률). 누가 무엇을 골랐는지는 서버가 내려 주지 않고, 참여 5명 미만이면 정답률도 숨긴다(적으면 개인 답이 짐작된다).
- **하지 않기로 한 것**: 추첨 경품 — 경품 법규 검토와 매장 수령 관리가 붙어 비용이 크다. 포인트로 먼저 검증한다.

## 권한

| 행동 | 독자 | 사장님 |
|---|---|---|
| 퀴즈 목록·마감 뒤 정답 보기 | O | O (자기 서점) |
| 풀고 제출 (1회) | O | X |
| 내 결과 보기 | 본인 것만 | X |
| 퀴즈 만들기·게시·조기 마감 | X | 자기 서점 |
| 참여 수·문항별 정답률 보기 | X | 자기 서점 (5명 이상일 때 정답률) |

- 비로그인은 목록만 보고 풀 때 로그인으로 안내한다. 직원·운영자 권한은 사장님과 같게 두되 운영자 조작은 감사 기록(`context/rules.md`).

## 상태 변화

| 지금 | 계기 | 다음 | 되돌리기 |
|---|---|---|---|
| (없음) | 사장님 게시 | 진행 중 — 이후 문항·정답 잠김 | 불가 |
| 진행 중 | 마감일 지남 또는 사장님 조기 마감 | 마감 — 정답·결과 공개 | 불가 |
| 마감 | 마감 24시간 뒤 | 보상 지급됨 — 만점자에게 포인트 | 불가 (운영자 회수만) |

- 마감 직후 제출 요청은 "이미 마감됐어요"로 거절하고 정답 화면으로 보낸다(조용히 버리지 않는다).

## 숫자

| 값 | 얼마 | 운영이 배포 없이 바꾸나 |
|---|---|---|
| 퀴즈당 문항 수 | 3~5개 (선택지 4개 고정) | 아니오 |
| 만점자 1인 포인트 | 100P (이벤트 지급분) | 예 (→ 어드민 › 퀴즈 설정, 감사 기록) |
| 정답률을 보여 주는 최소 참여 수 | 5명 | 아니오 (개인정보 하한) |

## 기존 코드와의 관계

| 구분 | 무엇 | 근거 |
|---|---|---|
| 재사용 | 보상 지급 = 포인트 원장 이벤트 지급분 · 새 퀴즈·결과 알림 = 알림(묶음 10분 1건) · 퀴즈 신고 = 공통 신고 | `context/features.md` 포인트·알림·신고, `context/constraints.md` 재사용 |
| 신규 | 퀴즈·문항·제출 데이터, 파트너 퀴즈 화면, 어드민 › 퀴즈 설정 | 비슷한 기능 없음. 셸에 퀴즈 탭 자리가 아직 없다(`app-structure/shell.js`) |
| 충돌 | 사장님이 포인트를 직접 지급할 수 있나 — 포인트는 결제 적립분·이벤트 지급분뿐이고 이벤트 지급분은 책숲이 발행한다. 서점 부담이면 정산 차감이 필요한데 정산은 조회만 있다 | `context/constraints.md` "결제 적립 포인트 환불", `context/features.md` 정산 |
