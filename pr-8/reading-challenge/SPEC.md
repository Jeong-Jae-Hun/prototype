# 독서 챌린지 — 한 달에 정한 권수를 읽고 인증하면 포인트를 받는다

| 항목 | 내용 |
|---|---|
| 종류 | 기능 |
| 상태 | 초안 |
| 브랜드 | reader |
| 담당 | 기획 @ · 디자인 @ · 개발 @ |
| 현황 버전 | a1b2c3d |

## 결정

- 운영이 달마다 챌린지를 연다(예: 10월 3권). 독자는 다 읽은 책마다 **책 제목 + 한 줄 감상**으로 인증한다.
- 같은 책(ISBN)은 평생 한 번만 인정한다. 감상은 10자 이상.
- 보상은 **이벤트 지급 포인트**로, 기간이 끝나고 검수 뒤 한 번에 준다(부정 인증을 먼저 거른다).
- 인증은 기본 나만 보기.
- 하지 않기로 한 것: 순위표 — 경쟁보다 습관이 목적이고, 남의 독서 기록이 드러난다.

## 상태 변화

| 지금 | 계기 | 다음 |
|---|---|---|
| 진행 중 | 목표 권수 인증 | 달성 (보상 대기) |
| 진행 중 | 기간 끝남 | 기간 종료 — 보상 없음 |
| 달성 | 기간 끝 + 검수 | 보상 지급됨 |

## 기존 코드와의 관계

| 구분 | 무엇 |
|---|---|
