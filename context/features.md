# 이미 있는 기능

> 🧪 예시 — 가상의 제품 "팬온". 현황 버전 `a1b2c3d` (2026-10-07). [README](README.md)

프로토타입을 그리기 전에 여기서 "이미 있나"를 먼저 찾는다. 있으면 재사용하고, 명세의 「기존 코드와의 관계」에 적는다.

## 역할

| 역할 | 코드 이름 | 어떻게 정해지나 |
|---|---|---|
| 비로그인 | `guest` | 세션 없음 |
| 회원 | `member` | 로그인 |
| 멤버십 회원 | `subscriber` | 채널 멤버십 결제 중. **채널마다 따로** 정해진다 |
| 방송인 | `owner` | 채널 주인. 채널당 1명 |
| 매니저 | `manager` | 방송인이 지정. 채널당 최대 5명 |
| 운영자 | `admin` | 서비스 운영. 모든 조작에 감사 기록 |

## 기능

| 기능 | 무엇 | 권한 요지 | 재사용 포인트 |
|---|---|---|---|
| 채널 | 방송인 페이지. 소개·방송 일정·공지 | 읽기 누구나, 쓰기 방송인·매니저 | 채널 탭에 새 메뉴를 붙일 수 있다(탭 최대 6개) |
| 멤버십 | 채널별 월 구독. 가입 일수(`joinedDays`)를 센다 | 결제 회원 | **가입 일수는 이미 있다** — 새로 세지 않는다 |
| 포인트 | 충전·적립 포인트 원장. 충전분과 무료분을 나눠 기록 | 본인만 잔액 조회 | 차감·환불 API가 있다. **충전분 환불은 결제 취소 규정**을 따른다 |
| 1:1 메시지 | 회원 간 DM | 양쪽 회원 | 1:N 발송 기능은 없다. 메시지 저장소는 재사용 가능 |
| 클립 | 방송 구간 잘라 저장. 최대 3분 | 만들기 회원, 공개 범위는 방송인 설정 | 클립 목록·썸네일 API가 있다 |
| 투표 (게시판) | 게시글에 붙는 단순 투표 | 게시판 권한 따름 | 1인 1표·마감만 있음. 표 변경·비공개 집계는 없음 |
| 신고 | 모든 콘텐츠 공통 신고 접수·처리 | 접수 회원, 처리 운영자 | **신고는 이걸로 통일**한다. 기능마다 따로 만들지 않는다 |
| 알림 | 앱 푸시·알림함 | 본인 | 묶음 규칙이 있다(같은 종류 10분 1건) |

## 운영이 배포 없이 바꾸는 값 (지금 있는 것)

| 값 | 어디서 바꾸나 |
|---|---|
| 포인트 충전 상품·가격 | 어드민 › 포인트 상품 |
| 멤버십 가격 | 방송인 스튜디오 (상한은 운영) |
| 알림 묶음 간격 | 어드민 › 알림 설정 |

새 기능의 숫자를 "운영이 바꾼다"로 정하면, 어드민 화면이 같이 필요하다는 뜻이다. 명세에 그렇게 적는다.
